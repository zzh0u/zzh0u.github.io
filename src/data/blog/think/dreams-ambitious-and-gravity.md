去年在杭州参加了 AdventureX 2025，认识了原本在另一条时间线不会遇见的人。第一次知道，原来生活可以这样过，人生有这么多可能性，人真的可以做成这么多有意思的事——只要自己愿意动起来。自此，我心里种下了一颗名为野心的种子。

在 AdventureX 上，我们做的项目叫 YOLO（You Only Live Once）。理念是提供一个 web3 平台，让所有认可你的人成为你的第一位「投资人」，让每个人都有平等的起点。现在想来，那个 web3 的点子挺烂的，项目做得也很烂。当然，我要承担主要责任——那时候我还是个连 web 框架和 API 都不熟悉的人。但有关个人价值实现的部分，我依然愿意相信。后来，这个想法经过多轮迭代，变成了 Launchpad S1 的起点。

半年后，在即将接手产品一个模块的节点，我选择了裸辞。当时自然不会注意到家人的无奈和妥协，只有一股一往无前的热血。随后奔赴上海，和可豪、耳哥、林珑、炤姐、超宇一起筹备 Launchpad S1。大家都是很棒的人，热烈、直率、值得信赖。

一个多月的探索中，一场活动带来的各种琐事都需要我们自己解决。这让我想起冯骥在采访中说的：「最后让你痛苦的并不是远方的高山，而是脚底的沙子。沙子无穷无尽，但是你想走到那座山，就得忍受沙子如影随形的折磨。」

我本意是去帮忙写一套服务参赛选手的系统，但前几次沟通后就被告知取消了——最终也证明了这是个错误的决定。随后我像个 freelancer，哪里需要就做哪里。过程虽有曲折和误会，结果终究是好的。

我对 Launchpad S1 的看法是：一群心怀理想和志向的年轻人，对现实一次生涩的探索。

过完春节，我开始忙碌地找工作，在宁波、上海、杭州之间来回奔波。面试了不少公司，却没有收获。倒是经常出入各种 AI 活动，听人聊创业、融资、出海、扩张，恍惚间觉得自己也很厉害。

我自认对专业能力有信心，但第一份工作只有半年，工作经验严重不足，学历又毫无优势，在横向对比中天然不如别人。现实的引力狠狠地将我拉回了地面。

两个月颗粒无收后，我提前清空了出租屋，灰溜溜地回了老家继续找工作。又辗转了一个月，才找到一份满意的工作。这期间还去了一趟广东，感受到的只有格格不入。

这段时间像是给我沉重一击——原来那些 fancy 的活动根本与我无关。无他，我只是一个见证者而已。那些宏大的叙事，终究有一道隐形的准入门槛，而我，似乎天生就是被排除在外的人。

如今回看那些绚烂的世界，我感受到的只有敬畏。很感谢那段时光，让我见证过，也参与过那样的生活。所以现在，我可以抛去不切实际的幻想，脚踏实地地提升自己。

前阵子 AdventureX 2026 举办，我却没有报名。这样的活动很好，充满激情和梦想，但只需要体验一次就够了——体验过肾上腺素飙升、和团队一起创造的感觉，一次就够了。但我很想去现场，去见见我的朋友们，看看他们过得怎么样，找一家酒馆，畅谈生活中的美好与不幸。可惜终究没能去成，说起来有些遗憾。

现在，我正学着和引力共存。了解它，适应它，然后挑战它。我不知道将来会不会重新捡起那个梦，但至少不是现在。

我不知道将来会是什么样，但至少现在，稳稳当当地往前走吧。
